1. Install Python 3.10+  (python.org)
2. pip install -r requirements.txt
3. Get a token from @BotFather in Telegram (/newbot), then set it:
   Windows (CMD):  set BOT_TOKEN=123456:ABC...
4. Put an Ethiopic font named font.ttf in this folder
   (free: Noto Sans Ethiopic Bold from fonts.google.com). Windows also has Nyala.
5. python bot.py
